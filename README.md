# Delta's Roblox Script

This project is a Roblox script written in Luau that sets the walkspeed for players to 20 and hides it from detection. It is designed to be placed in the workspace of a Roblox game.

## Install

1. Download the `DeltaScript.lua` file from the GitHub repository.
2. Open Roblox Studio.
3. Create a new place or open an existing one.
4. Navigate to the workspace in the hierarchy.
5. Insert the script into the workspace.

## Use

1. Once the script is inserted into the workspace, it will automatically run when the game starts.
2. Players who join the game will have their walkspeed set to 20.
3. The script will also hide the walkspeed from detection by monitoring changes to the walkspeed property and resetting it to 20 if it is changed.
